# 性能测试用例标准

> 本标准用于增强性能需求、QPS/RT指标类文档的测试用例覆盖。

---

## 一、适用范围

- 性能需求文档
- SLA 协议
- QPS/RT 指标说明
- 吞吐量要求文档
- 压测方案文档

---

## 二、性能指标术语

| 指标 | 全称 | 说明 | 目标示例 |
|-----|------|------|---------|
| RT | Response Time | 响应时间，从发起到返回 | P99 < 200ms |
| QPS | Queries Per Second | 每秒查询数 | 1000 TPS |
| TPS | Transactions Per Second | 每秒事务数 | 500 TPS |
| Latency | 延迟 | 网络传输+处理时间 | < 50ms |
| Throughput | 吞吐量 | 单位时间处理量 | 1000 req/s |
| Concurrency | 并发数 | 同时处理的请求数 | 100 concurrent |

## 三、测试类型与策略

### 3.1 基准测试（Baseline Test）

```
目的：确定单业务线、单用户的性能基线
方法：逐步增加压力，找到最佳性能点
指标：响应时间、吞吐量
```

### 3.2 负载测试（Load Test）

```
目的：验证正常负载下的系统表现
方法：在预期峰值负载下持续运行
指标：RT、QPS、错误率
```

### 3.3 压力测试（Stress Test）

```
目的：找出系统的极限
方法：超过预期峰值持续增压
指标：最大QPS、崩溃点
```

### 3.4 稳定性测试（Soak Test）

```
目的：验证长时间运行的稳定性
方法：在正常负载下持续运行24h+
指标：内存泄漏、连接池耗尽、错误率趋势
```

## 四、测试场景设计

### 4.1 核心业务性能测试

每个核心接口需覆盖：

| 场景 | 并发数 | 持续时间 | 目标RT | 目标QPS |
|------|--------|---------|--------|---------|
| 单接口基准 | 1 | 1min | P99 < 100ms | - |
| 单接口负载 | 50 | 5min | P99 < 200ms | > 500 |
| 单接口压力 | 100+ | 3min | P99 < 500ms | 最大值 |
| 混合接口 | 50 | 10min | P99 < 300ms | > 800 |

### 4.2 典型用户场景性能测试

端到端业务场景：

```
场景1：用户登录到下单全流程
  - 步骤：登录 → 浏览商品 → 加入购物车 → 提交订单
  - 并发：100用户
  - 目标：全流程 P99 < 2s

场景2：数据查询报表
  - 步骤：进入报表 → 选择时间 → 查询 → 导出
  - 并发：20用户
  - 目标：查询 P99 < 5s

场景3：海量数据搜索
  - 步骤：输入关键词 → 搜索 → 分页浏览
  - 并发：200用户
  - 目标：搜索 P99 < 1s
```

### 4.3 边界条件性能测试

| 场景 | 测试内容 |
|------|---------|
| 数据量边界 | 最大数据量下的查询性能 |
| 并发边界 | 最大支持并发数 |
| 流量边界 | 系统能承受的最大QPS |
| 组合边界 | 多指标同时达到极限 |

## 五、性能用例命名规范

```
【性能】场景名称_并发数并发_持续时间_指标目标

示例：
【性能】用户登录_100并发_5分钟_P99<200ms
【性能】商品查询_500并发_3分钟_QPS>2000
【压力】订单创建_逐步增压至崩溃
【稳定】系统运行_50并发_24小时_内存无泄漏
```

## 六、用例结构模板

### 6.1 性能基准用例

```
用例名称：【性能】XXX接口_基准测试
接口：/api/xxx

测试参数：
  - 并发数：1
  - 持续时间：60秒
  - 预热时间：10秒
  - 请求间隔：0ms（全力压测）

监控指标：
  - RT_avg：平均响应时间
  - RT_p95：95分位响应时间
  - RT_p99：99分位响应时间
  - QPS：每秒请求数
  - 错误率：失败请求/总请求

验收标准：
  - RT_p99 < 100ms
  - 错误率 < 0.1%
```

### 6.2 负载测试用例

```
用例名称：【性能】XXX接口_负载测试
业务场景：正常峰值运营

测试参数：
  - 并发数：50
  - 持续时间：5分钟
  - 目标QPS：500

监控指标：
  - RT_p50/p90/p99
  - QPS
  - CPU使用率
  - 内存使用率
  - 连接池使用率

验收标准：
  - RT_p99 < 200ms
  - QPS >= 500
  - CPU < 70%
  - 错误率 < 1%
```

### 6.3 稳定性测试用例

```
用例名称：【性能】XXX系统_24小时稳定性测试

测试参数：
  - 并发数：30
  - 持续时间：24小时
  - 总请求量：约100万次

监控指标：
  - 错误率趋势
  - 内存使用趋势
  - 连接池使用趋势
  - GC频率
  - RT趋势

验收标准：
  - 全程错误率 < 0.5%
  - 内存无持续增长（无泄漏）
  - RT无明显劣化
```
